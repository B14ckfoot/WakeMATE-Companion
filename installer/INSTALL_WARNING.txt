WakeMATE Companion can expose this computer to authenticated control from another paired device.

Important:

- Remote access is disabled by default.
- UDP discovery is disabled by default.
- If you enable remote access, devices on your local network may be able to reach this app.
- Anyone with the pairing token may be able to control this computer according to the features you enable.
- Only enable remote input and power controls on devices and networks you trust.
- Rotate the pairing token if it may have been exposed.

By continuing, you acknowledge that you understand these risks and will configure the software appropriately.
