## Local Device Data

WakeMATE Companion may store the following locally:

- device name
- pairing token
- bind and discovery settings
- local feature flags such as remote access, input control, and power control

This data is stored in the user app-data directory unless changed by the user or installer.

## Network Behavior

- By default, remote access is disabled.
- By default, UDP discovery is disabled.
- If the user enables remote access, the app can receive authenticated commands over the local network.
- If the user enables discovery, the app replies to a local-network discovery message with limited device metadata.
